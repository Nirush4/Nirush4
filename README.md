## 👨🏽‍💻 Om meg

Jeg er en frontend-utvikler og backend-student med en sterk bakgrunn på 8 år innen grafisk design. Jeg har fagbrev i frontend-utvikling fra Noroff Oslo, hvor jeg oppnådde toppkarakterer (A) i alle fag og mottok prisen for beste studentarbeid innen frontend-utvikling i 2025.

Jeg har praktisk erfaring som frontend-intern hos Publicis Norway, der jeg bygget webapplikasjoner i React og TypeScript, håndterte API-integrasjoner og samarbeidet tett i tverrfaglige smidige team.

Med 8 års erfaring fra grafisk design kombinerer jeg dyp designforståelse med solid teknisk utvikling for å bygge brukervennlige, tilgjengelige (WCAG) og visuelt sterke grensesnitt. Jeg liker å omsette Figma-design til funksjonelle, høyytelses applikasjoner ved hjelp av React og TypeScript.

Jeg er spesielt interessert i å skape intuitive brukeropplevelser og forbedre navigasjon i digitale produkter. Jeg har også erfaring med CI/CD i Azure DevOps, versjonskontroll med Git og GitHub, og studerer nå nettbasert backend-utvikling for å utvide kompetansen min mot å bli en fullstack-utvikler.
