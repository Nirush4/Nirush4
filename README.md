# 👨🏽‍💻 Om meg:
Jeg er en frontend-utvikler og backend-student med en sterk bakgrunn på 8 år innen grafisk design. Jeg har en fagbrev i frontend-utvikling fra Noroff Oslo, hvor jeg oppnådde toppkarakterer (A) i alle fag og mottok beste studentarbeid innen front-end-utvikling i 2025.

Jeg har praktisk erfaring som frontend-intern hos Publicis Norway, der jeg bygget webapplikasjoner i React og TypeScript, håndterte API-integrasjoner og samarbeidet tett i tverrfaglige smidige team.

Med 8 års erfaring fra grafisk design kombinerer jeg designforståelse med utvikling for å bygge brukervennlige, tilgjengelige (WCAG) og visuelt sterke grensesnitt. Jeg liker å omsette Figma-design til funksjonelle, høyytelses applikasjoner ved hjelp av React, og TypeScript.

Jeg er spesielt interessert i å skape intuitive brukeropplevelser og forbedre innholdsleting i digitale produkter. Jeg har også erfaring med CI/CD i Azure DevOps, versjonskontroll med Git og GitHub, og studerer nå nettbasert backend-utvikling for å utvide kompetansen min mot å bli en full-stack-utvikler.

## 👯 Samarbeidsinteresser
Jeg ønsker å samarbeide om:
- Frontend-utvikling og UI-designprosjekter som sømløst kombinerer kreativt design med solid teknisk gjennomføring
- Open source-prosjekter med fokus på tilgjengelig UI/UX, brukeropplevelse og moderne webapplikasjoner
- Tverrfaglige team-samarbeid som bygger bro mellom designere og utviklere

## 🌱 Lærer akkurat nå
- Nettbasert backend-utvikling for å utvide kompetansen min mot å bli full-stack-utvikler
- Avanserte TypeScript-teknikker og moderne React-mønstre
- Beste praksis for universell utforming og web-tilgjengelighet (WCAG)
- CI/CD-arbeidsflyter og moderne frontend-verktøy

## ⚡ Fun Fact
I believe every bug is just a hidden feature waiting to be discovered 🚀
